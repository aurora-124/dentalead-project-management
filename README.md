# DentaLead — Academic Project Management Plan

## Overview
DentaLead is a proposed platform designed to help dental students find patients for clinical training and help patients access dental services more easily.

## My Role
Prepared the academic project management plan and supporting documentation.

## Project Planning Deliverables
- Project charter
- Scope definition
- Work Breakdown Structure (WBS)
- Project schedule and milestones
- Resource planning
- Risk analysis
- Estimated project budget

## Planned Product Deliverables
1. Mobile application
2. Patient registration system
3. Appointment booking and scheduling feature

## Tools
- Microsoft Word
- Microsoft Excel
- Microsoft PowerPoint

## Budget
Estimated budget: EGP 100,000.

## Project Status
This repository contains an academic planning proposal. The proposed product was not implemented as part of this project.
